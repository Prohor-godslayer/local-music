# Локальная музыка

Версия 1.1.0. Плеер файлов с твоего устройства: очередь, плейлисты, громкость, кроссфейд, таймер сна. DJ собирает очередь только из этих файлов и только моделью клиента.

Чужих каталогов, роликов и потокового радио нет. Кнопка обновления в Таверне — это её `git pull` этого репозитория, не запрос плеера.

## Установка в SillyTavern

Кнопка обновления есть только у установки из git.

1. «Расширения» → «Установить расширение».
2. Адрес: `https://github.com/Prohor-godslayer/local-music`. Ветка `main`.
3. В «Управление расширениями» карточка «Локальная музыка», версия 1.1.0.
4. Включи «Уведомлять об обновлениях расширений», если пункт есть.

Кнопка ♪ у края чата. Пункт меню — «Локальная музыка».

Папку без git в `data/<пользователь>/extensions/local-music` удали и поставь по ссылке.

### Когда Таверна говорит, что нужно обновить

`"version": "1.1.0"` и `"auto_update": true`. Сравнение идёт с `origin/main`. Кнопка на карточке по-английски — **Update available**, по-русски — перевод из языкового пакета. Нажатие делает `git pull`.

## Установка в Tavo

1. Скачай `tavo/local-music.tpg`: https://github.com/Prohor-godslayer/local-music/blob/main/tavo/local-music.tpg
2. Импортируй плагин. Сетевого права нет. Нужны сообщения, переменные, файл и генерация.
3. Открытие: кнопка ♪, действие ввода «Локальная музыка», боковая панель.

Новую версию ставь повторным импортом `.tpg`. Версия плагина 1.1.0.

## Как пользоваться

1. «Библиотека» → «Добавить файлы». Бери аудио с диска. Имя вида `Исполнитель - Название` само режется на артиста и название.
2. «В очередь» кладёт трек в конец. В «Очереди» строка включает этот трек, крестик убирает его из очереди, не из библиотеки.
3. На главном экране: предыдущий, играть или пауза, следующий. Если браузер заблокировал звук, нажми «Играть» ещё раз: жест нужен самому браузеру.
4. Ползунок громкости пишется в настройки клиента. Кроссфейд 0, 2 или 5 секунд.
5. Таймер сна: 15, 30 или 60 минут, затем плеер встаёт на паузу. «выкл» снимает таймер.
6. «Сохранить очередь как плейлист» запоминает порядок по id. Нажатие на плейлист подставляет его в очередь. Удалённые из библиотеки файлы в очередь не возвращаются.
7. «DJ» читает последние реплики и просит модель вернуть JSON-массив id из библиотеки. Чужие id выкидываются. Если модель не назвала ни одного твоего файла, очередь не меняется.
8. Дырка в очереди (файл стёрт, а id остался) при воспроизведении пропускается.

Файлы живут в IndexedDB этого браузера, база `local-music`. Другой браузер и другой профиль их не увидят. Плейлисты и очередь — в настройках клиента, без самих байтов музыки. Перенос музыки на другой компьютер — заново добавить файлы. Очередь без файлов играть не начнёт.

## Где лежат данные

SillyTavern: `settings.json`, ключ `local_suite_music`, поле `meta`. Tavo: `lx_music_meta` в файле плагина, затем переменная и `localStorage`.
