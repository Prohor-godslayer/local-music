# Локальная музыка

Плеер ваших аудиофайлов. Файлы лежат в IndexedDB этого браузера. Плейлисты, очередь, громкость, кроссфейд и таймер сна хранятся в данных клиента. Диджей просит модель клиента выбрать треки только из этой библиотеки.

Чужие каталоги и потоковое воспроизведение отсутствуют.

## SillyTavern

Скопируйте репозиторий в `data/<пользователь>/extensions/local-music`. Панель: кнопка у края чата и пункт «Локальная музыка».

## Tavo

Импортируйте `tavo/local-music.tpg`.
